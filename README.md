A program that draws a newspaper front page summing up Wednesday 18 November 2026 in one image: APEC opens in Shenzhen with a Trump–Xi–Putin trilateral set for the next day, Ukraine hits the Crimea bridge, the QUAD meets in Manila, the US loses its measles-free status, Mongolia's president resigns, Iran hits a US radar in Bahrain, and the UK sanctions settlement firms. `main.ts` (Node 22, standard library only) renders the page with a hand-written PNG encoder and a 5×7 bitmap font, so two runs write byte-identical output with no network.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
